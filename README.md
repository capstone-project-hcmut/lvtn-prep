# lvtn-prep

Tài liệu chuẩn bị buổi bảo vệ luận văn của nhóm Reeldemy (HK252-DAGD1-108).

- `ke-hoach-slide.html`: kế hoạch slide, phân bổ thời gian, kịch bản demo, slide dự phòng
- `hoi-dap-checklist.html`: câu hỏi cần chuẩn bị và checklist trước buổi bảo vệ
- `index.html`: trang mở đầu dẫn tới hai phần trên

Mở `index.html` bằng trình duyệt là xem được, không cần cài đặt gì. Trạng thái checklist được lưu trong trình duyệt của từng người (localStorage), không đồng bộ giữa các máy.
